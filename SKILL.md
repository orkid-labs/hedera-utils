# hedera-utils

hedera-utils wraps the Hedera SDK patterns Orkid uses in production: HCS topic logging with retry, milestone tracking for multi-step settlements, and React components for HCS-aware dashboards.

## When to use

Building on Hedera HCS/HTS in TypeScript, or integrating Orkid's Hedera settlement telemetry.

## Install

```
npm install @orkid-labs/hedera-utils
```
